# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

Pinned to SDK 54 deliberately: the standard Expo Go app (App Store / Play
Store) only supports SDK 54 as of writing. Don't bump past it without
checking Expo Go's currently-supported SDK first, or `npx expo start` will
build fine but crash instantly when opened in Expo Go.
